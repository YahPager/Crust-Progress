# Crust Progress

Crust is a planned native systems language with C-style syntax and `.cru`
source files. Its goal is first-class interoperability with C, C++, and Rust,
with Windows x64 as the initial target.

Maintained by [YahPager](https://github.com/YahPager).

## Current status

**Design direction agreed; compiler implementation has not started.**

No working Crust compiler, native interoperability, or Broadcast: The Works
(BTW) audio integration has been verified. The first application goal is a
recorded-audio demonstration for BTW.
